在 Mac 上运行 Windows 程序，不用虚拟机

你不需要在 Mac 里再装一台 Windows。Windows 自带一种叫 RemoteApp 的能力：远程会话只发布单个程序窗口。kkguai 是免费开源的 macOS 客户端，负责把这些窗口接到你的 Mac 上。这篇指南从零讲到第一个窗口出现。

RemoteApp 是什么，和「远程桌面」有什么不同

远程桌面协议（RDP）默认把一整块 Windows 桌面串流成一个窗口：你看到的是 Windows 的开始菜单、任务栏和壁纸，只是装进了 Mac 的一个大窗口里。

RemoteApp 是 RDP 的另一半能力：会话只把一个程序的窗口交给客户端，Windows 的桌面、任务栏和开始菜单都不会出现。程序窗口直接显示在 Mac 桌面上，可以拖动、缩放、最小化，也能和平常的 Mac 应用并排摆放。

  • 程序仍然运行在 Windows 上。文件、数据库、公司内网软件都留在那台电脑里，Mac 只负责显示和输入。
  • 每个程序一个窗口、一个 Dock 图标。Spotlight、Launchpad、⌘Tab 都能找到它。
  • 不用虚拟机。Mac 不分配内存和磁盘给 Windows，也不跑第二套驱动。

公司里通常用 RDS / AVD 部署 RemoteApp；kkguai 面向的是另一种常见情况：你手边已经有一台 Windows 专业版电脑，只想在 Mac 上打开它的几个程序。发布包里的注册表文件会在那台电脑上打开单机的 RemoteApp 能力，微软没有为这种用法提供图形界面。

需要准备什么

两台机器之间只要有网络可达的路径即可，不需要公网 IP。
项目要求
MacmacOS 14 或更新，Apple Silicon（M 系列）。当前发布包不支持 Intel Mac，可用源码自行构建。
Windows 主机Windows 10 / 11 专业版或企业版，或 Windows Server。家庭版不能作为 RDP 主机。
开机与联网Windows 电脑要开着并保持网络连接。程序在那边运行，关机或休眠后窗口就没了。
网络同一个局域网，或 VPN、Tailscale 等能互通的路径。建议不要直接把 3389 端口暴露到公网。
权限在 Windows 上需要一次管理员权限：开启远程桌面、导入注册表、重启。
账号一个设置了密码的 Windows 账号。RDP 不接受空密码。

家庭版怎么办：Windows 家庭版被微软限制为不能接受远程桌面连接，没有开关可以打开。需要升级到专业版，或者改用虚拟机方案（见 方案对比）。

五步打开第一个窗口

下面的步骤假设两台机器已经能互相 ping 通。全程大约十分钟，大部分时间花在 Windows 重启上。

  1. 检查 Windows 版本并开启远程桌面

    在 Windows 上按 Win + R，输入 winver 确认是专业版或企业版。然后打开「设置 → 系统 → 远程桌面」，把开关打开。

    也可以在管理员 PowerShell 里直接运行下面两行，效果相同：

    Windows · 管理员 PowerShell
    # 允许远程桌面，并放行防火墙（规则组 ID 与系统语言无关）
Set-ItemProperty 'HKLM:\System\CurrentControlSet\Control\Terminal Server' -Name fDenyTSConnections -Value 0
Enable-NetFirewallRule -Group '@FirewallAPI.dll,-28752'
  2. 导入 enable-remoteapp.reg，然后重启

    从 最新 Release 里找到 enable-remoteapp.reg，右键「以管理员身份运行」或在注册表编辑器里导入。这一步是必需的——它负责打开单机 RemoteApp 发布。

    • 如果同时有 single-session.reg，按你的使用方式决定是否导入（见下方说明）。
    • 导入后重启 Windows，新的策略才会生效。

    如果你在那台 Windows 上一直保持着一个桌面登录会话，专用会话可能无法创建。single-session.reg 用于这种单会话场景；不确定就先不导入，遇到「已登录」类错误再回来看这一步。

  3. 在 Mac 上安装 kkguai

    下载 kkguai-0.2.9-macos-arm64.dmg，打开后把 kkguai 拖进「应用程序」。发布包还没有经过 Apple 公证，首次打开前在终端执行一次：

    macOS · Terminal
    # 去掉下载隔离标记（每次安装只需一次）
xattr -dr com.apple.quarantine /Applications/kkguai.app
open /Applications/kkguai.app

    跳过这一步，macOS 会提示「kkguai 已损坏」或「无法验证开发者」。原因与处理方式见 常见问题。

  4. 填入地址和账号，连接

    在 kkguai 里新建连接，填写 Windows 电脑的主机名或 IP（局域网里通常形如 192.168.1.x）、用户名和密码。Tailscale 用户直接填 Tailscale 分配的地址或 MagicDNS 名称。

    第一次连接时 Windows 可能会询问是否信任证书，按提示确认即可。会话本身是加密的。

  5. 从开始菜单打开程序

    连接后会出现一个 Windows 11 风格的开始菜单，列出那台电脑上可用的程序。点开任意一个，它就会变成 Mac 上的一个独立窗口，并在 Dock 里得到自己的图标。

    之后可以同时打开多个程序，它们互不影响，也可以各自全屏或分屏。

卡住了怎么办

最常见的几种情况：

  • 连接被拒绝或超时：先确认 Windows 版本是专业版，远程桌面开关已打开，防火墙放行了 3389；再用另一台设备 ping 一下那台电脑。
  • 开始菜单里没有程序：通常是 enable-remoteapp.reg 没导入，或者导入后没有重启。
  • 提示桌面会话已登录：Windows 上已有同一账号的桌面登录。退出那个桌面会话，或使用 single-session.reg。
  • Mac 说 app 已损坏：那是下载隔离标记，不是真的损坏。执行上面的 xattr 命令即可。
