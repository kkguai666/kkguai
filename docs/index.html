让它「像本地应用」的那些细节。

RemoteApp 本身不是新技术。kkguai 花力气的地方，是让它在 Mac 上每天都能顺手用。

Retina 是真的 2 倍

会话按 200% 协商、按 2 倍像素渲染，坐标做 1/2 点映射。文字放在 Mac 原生界面旁边也不发虚。

用 Mac 输入法打中文

拼音在 Mac 上合成，候选框在 Mac 上弹出，选好的字以 Unicode 发过去。不会远端再合成一遍，也不会丢字。

光标跟着程序变

文本、链接、窗口边缘，光标形状和热点都来自 Windows。看到的光标在哪，点下去就在哪。

拖动在本地完成

移动和缩放先在 Mac 本地完成，松手后才把新位置告诉远端。窗口不会拖在你手后面。

每个程序自己进 Dock

远端程序有自己的 Dock 图标，Spotlight、Launchpad、⌘Tab 里都能找到。还带一个 Windows 11 风格的开始菜单。

多显示器不用重配

Mac 的显示器布局会同步给远端会话，窗口可以跨屏拖动，不用每次重新摆一遍。

需要一台开着的 Windows 10 / 11 专业版电脑，以及两台机器之间网络可达：局域网、VPN、Tailscale 都行。

在 Windows 上打开远程桌面

在管理员 PowerShell 里运行下面两行，再导入 Release 里的 enable-remoteapp.reg（管理员权限，必需）。Windows 家庭版不能做 RDP 主机。

在 Mac 上装 kkguai

下载 .dmg，把 kkguai 拖进「应用程序」。发布包还没做 Apple 公证，首次打开前执行一次 xattr 那一行。

连接，挑一个程序

填 Windows 电脑的地址和账号，从开始菜单里打开程序。每个程序都会有自己的 Mac 窗口和 Dock 图标。

Windows · 管理员 PowerShell 
# 允许远程桌面，并放行防火墙（语言无关的规则组 ID）
Set-ItemProperty 'HKLM:\System\CurrentControlSet\Control\Terminal Server' -Name fDenyTSConnections -Value 0
Enable-NetFirewallRule -Group '@FirewallAPI.dll,-28752'
macOS · Terminal 
# 首次打开前去掉隔离标记（只需一次）
xattr -dr com.apple.quarantine /Applications/kkguai.app
open /Applications/kkguai.app

常见问题。

需要什么版本的 Windows？+
Windows 10 / 11 专业版（或企业版），并开启远程桌面。家庭版不能作为 RDP 主机。
Windows 电脑要一直开着吗？+
要。程序本身运行在那台机器上，kkguai 只负责显示窗口和发送输入。那台电脑休眠或断网，窗口就会消失。
不在同一个局域网能用吗？+
能。VPN、Tailscale、端口转发都可以。建议用 VPN 或 Tailscale，不要把 3389 直接暴露在公网。
为什么首次打开要执行 xattr？+
发布包是 ad-hoc 签名，还没经过 Apple 公证，所以下载后 macOS 会隔离它。去掉隔离标记只需要一条命令，每次安装做一次。
和 Parallels 有什么区别？+
Parallels 在 Mac 里跑一整台 Windows 虚拟机，要买它的订阅，还要 Windows 授权；kkguai 用你已有的 Windows 电脑，不花钱，也不占 Mac 的内存和 CPU。代价是那台电脑必须在线、网络可达。
Intel Mac 能用吗？+
当前发布包只支持 Apple Silicon。Intel Mac 可以从源码构建，步骤见仓库的构建说明。
安全吗？+
连接走标准 RDP，传输加密。把它放在局域网、VPN 或 Tailscale 里，给 Windows 账号设一个真实密码，不要把 RDP 直接暴露到公网。

你已有的 Windows 电脑，就是 Mac 缺的那一半。
