kkguai, Parallels, Windows App, UTM: which one fits

All four let you use Windows programs on a Mac, but they solve different problems. Some people need "a PC inside the Mac"; others just want the ERP and three old tools from the company PC always at hand. Understand the premise first, then pick the tool.

How each option works

kkguai

Bring your existing Windows PC's apps to the Mac

Using the RemoteApp capability built into Windows, the remote session publishes a single program window, and kkguai presents it as a native Mac window. Windows keeps running on that PC; the Mac spends no RAM or disk on it.

Requires: a Windows 10/11 Pro PC that stays on, reachable from the Mac.

Parallels Desktop

Run a whole Windows virtual machine inside the Mac

A VM, and its Coherence mode draws Windows program windows straight onto the Mac desktop — no second computer needed. Windows 11 ARM runs on Apple Silicon; x86 programs go through emulation.

Requires: a subscription and a Windows licence; uses the Mac's RAM, CPU and disk.

Windows App

Microsoft's own remote desktop client

Free client for another Windows PC, a Windows 365 Cloud PC, or Azure Virtual Desktop. By default you get an entire Windows desktop inside one window.

Requires: a remotely reachable Windows host; per-app publishing needs AVD/RDS infrastructure.

UTM

A free, open-source virtual machine

Built on QEMU and Apple's Virtualization framework, it runs Windows or Linux VMs on the Mac. There is no Coherence-style window integration — you see a full Windows desktop.

Requires: a Windows licence, and the willingness to set up and maintain a VM.

"Windows App" is the new name of Microsoft's Remote Desktop client. It is not the same thing as Windows 365 or Azure Virtual Desktop — the client itself is free.

When kkguai is the right choice

  • You already have that Windows PC, and it is already on. A work desktop, a home tower, or the machine that runs the ERP or accounting software.
  • You need a few programs, not a whole Windows desktop. Put the ERP, inventory tool, older Office or industry software on the Mac desktop next to Mail and the browser.
  • You don't want a subscription for occasional Windows apps, and don't want a VM eating 8 GB of RAM and tens of gigabytes of disk.
  • You care about window behaviour: Retina sharpness, Mac input methods for Chinese, a Dock icon per app, matching multi-monitor layouts.

Step-by-step setup is in the RemoteApp guide.

When it is not

This is the most important part of the page. kkguai is a RemoteApp client; it doesn't change these facts:

  • That Windows PC must stay on and online. Travel, a network drop or sleep mode means no apps. A VM doesn't have this problem.
  • It must be Pro or Enterprise. Windows Home cannot host Remote Desktop, and there is no workaround.
  • Heavy 3D, video editing and games are out of scope. Frames travel over the network; latency and quality depend on it. Use a VM or native Windows for that.
  • It doesn't give you a complete Windows desktop. If you need the Start menu, taskbar and File Explorer as a whole, use Windows App or a VM.
  • It isn't a Microsoft-supported deployment. If your company manages RemoteApp through RDS or AVD, use the company's setup.

In one line: if you can't say where Windows will run, you probably need a virtual machine; if a Windows PC is already running somewhere, kkguai is the least work.

Three common myths

"Free can't be as good as paid"

They aren't the same product. Parallels sells a computer inside your Mac; kkguai (for free) brings windows over from a computer you already have. The former does far more; the latter does its own job at no cost.

"RemoteApp needs enterprise servers"

Microsoft's official RemoteApp deployment is built on RDS. But Windows Pro keeps the single-machine RemoteApp publishing capability — it just has no UI. enable-remoteapp.reg in the release turns it on. That also means kkguai depends on existing Windows behaviour, which is worth watching after major Windows upgrades.

"Remote desktop always looks blurry"

Blur usually comes from negotiating at 100% and then scaling up on the Mac. kkguai negotiates the session at 200% and renders at 2× pixels, so text stays sharp on Retina. Smoothness still depends on the network.
