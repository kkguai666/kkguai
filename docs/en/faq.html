The basics

What is kkguai?+

kkguai is a free, open-source macOS RemoteApp client built on Pstsc (FreeRDP). It connects to an existing Windows 10/11 Pro PC and turns individual Windows programs into native Mac windows: one window and one Dock icon per app, side by side with your normal Mac apps.

It is not a virtual machine and not a full-screen remote desktop. The programs run on that Windows PC; the Mac only displays them and sends input.

Which Windows edition do I need?+

Windows 10 or 11 Pro or Enterprise, or Windows Server, with Remote Desktop enabled. RDP rejects blank passwords, so the Windows account needs one.

One command to check the edition: press Win + R and type winver.

Can Windows Home host it at all?+

Not as a host. Microsoft restricts Windows Home so it cannot accept Remote Desktop connections. There is no switch in Settings and no reliable registry workaround. This is a Windows product-line limit, not a kkguai one.

Three realistic paths:

  • Upgrade Home to Pro (you'll need an upgrade purchase or a new licence).
  • Run Windows in a virtual machine with Parallels Desktop or UTM — the guest edition doesn't matter for RemoteApp.
  • Run the program on a PC that is already Pro. See the comparison.
Does the Windows PC have to stay on?+

Yes. The programs run on that machine; kkguai only displays the windows and sends input. If it sleeps, shuts down or loses the network, the windows on the Mac disappear.

If it sleeps often, turn sleep off in Windows power settings — an office desktop is usually always on anyway.

Can Windows Server be the host?+

Yes. Windows Server ships with Remote Desktop Services and works as a RemoteApp host after importing enable-remoteapp.reg. Licensing rules for multi-user server setups are up to your environment; kkguai doesn't change them.

Install and first launch

Why do I have to run xattr before the first launch?+

The release is ad-hoc signed but not notarized by Apple. macOS attaches a quarantine flag (com.apple.quarantine) to downloaded apps, and an un-notarized app carrying it is refused by the system.

Removing the flag takes one command, once per install:

macOS · Terminal
xattr -dr com.apple.quarantine /Applications/kkguai.app

You won't need it again after that.

What happens if I skip xattr? Is there another way?+

macOS will say "kkguai is damaged and can't be opened" or "cannot verify the developer". The file isn't damaged; it's the quarantine policy.

Besides xattr, you can right-click the app in Finder and choose Open, then confirm once more; or click "Open Anyway" in System Settings → Privacy & Security. Both work for the current install only, and the wording varies by macOS version. The command line is the most reliable.

Do I have to reboot after importing enable-remoteapp.reg?+

Yes. The registry changes affect how the Remote Desktop service behaves across sessions, and they settle after a restart. If the Start menu shows no apps, the first two things to check are whether you rebooted and whether the import was done as administrator.

What if the same account is already signed in to a desktop session?+

In single-session mode, a desktop login with the same account can prevent a new app session from starting; kkguai reports an "already signed in" style error. Sign the desktop session out on that PC, then connect.

If you want a desktop login and RemoteApp to coexist, follow the release notes for single-session.reg. If unsure, leave it out and try it only if you hit the error.

Day to day

Does it support multiple monitors?+

Yes. Your Mac display layout is mirrored to the remote session, so windows can be dragged across screens without rearranging them each time. External displays, Studio Display and clamshell-with-external-monitor setups all follow the Mac's layout.

Can I type Chinese, Japanese or Korean with my Mac input method?+

Yes. Pinyin is composed on the Mac, the candidate window appears on the Mac, and finished characters are sent to Windows as Unicode. The remote side does not compose them again, so you don't get doubled text or dropped characters. Japanese and Korean input use the same mechanism.

Does it work on Intel Macs?+

The current release is Apple Silicon only (M-series), with macOS 14 or later.

Intel Macs can build from source. The repository has build instructions; you'll need Xcode and the FreeRDP dependencies. The result is the same functionality, but there is no ready-made package or signature.

Can I open several apps at once?+

Yes. Apps from the Start menu open at the same time, each with its own Mac window and Dock icon, and each can go full screen, tile, or sit on a different display. They share the one connection to the Windows PC.

Security and networking

Can I use it outside my LAN?+

Yes. Any reachable network path works: a VPN, Tailscale or a port forward. Tailscale gives you a fixed address or MagicDNS name for the PC — put it straight into kkguai.

Prefer a VPN or Tailscale over forwarding port 3389 on your router to the internet.

Is it secure? How does RDP over LAN, VPN and Tailscale compare?+

The connection uses standard RDP, encrypted in transit. How safe it is depends mostly on where you expose the host:

  • LAN: the smallest exposure. Only devices on the same network can try, and a strong password plus account lockout is enough for everyday use.
  • VPN: traffic sits inside an encrypted tunnel and the RDP port is invisible from outside. Security depends on the VPN; corporate VPNs usually add access control.
  • Tailscale: a point-to-point encrypted network on WireGuard, with devices authenticating each other and no port open to the internet. The easy choice for individuals.

Don't map 3389 directly to the internet. It attracts automated brute force, and no password makes that worth the risk. Use an account with a password and keep Network Level Authentication enabled in Windows.

Does my data go through a third-party server?+

No. kkguai is a direct client: video and input travel over an RDP connection between the two machines, with no relay server and no account system. If you use Tailscale, traffic goes over Tailscale's encrypted network (usually peer-to-peer); that's separate from kkguai.

Alternatives and licensing

How is this different from Parallels Desktop?+

Parallels runs a whole Windows virtual machine inside the Mac and uses Coherence mode to draw program windows on the Mac desktop. It needs a subscription (from about $99/year) and a Windows licence, and it uses the Mac's RAM, CPU and tens of gigabytes of disk; in exchange it works offline and needs no second computer.

kkguai uses the Windows PC you already have, is free and open source, and costs the Mac almost nothing; in exchange that PC must stay on, be reachable, and run Pro. The full comparison is in Comparison.

Is it free? Is it open source?+

Free, MIT-licensed, source on GitHub. No subscription, no in-app purchase, no account. If it saves you a Parallels subscription, a star on the repo is the best thanks.

Why is it called RemoteApp? Is it the same as Microsoft's RemoteApp?+

RemoteApp is the RDP capability that publishes a single program window, and kkguai uses the one built into Windows. Companies usually deploy Microsoft's RemoteApp through RDS or AVD; kkguai targets a single Windows Pro PC and uses the registry file in the release to enable the capability there. At the protocol level it's the same thing; the deployment is different.
