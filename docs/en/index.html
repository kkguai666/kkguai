A concept view: Windows app windows, Mac window controls, one Dock icon each. Real screenshots coming from the community.

Not another remote desktop.

Remote desktop tools squeeze an entire Windows screen into one Mac window. kkguai does the opposite: it asks Windows for a single app, and gives that app its own native Mac window. Drag it, resize it, put it next to Mail — it behaves like any other app.

The details that make it feel local.

RemoteApp itself is old technology. What makes kkguai usable every day is the work done on the Mac side.

Retina, negotiated properly

The session is negotiated at 200% and rendered at 2× pixels, with 1/2-point coordinate mapping. Text stays sharp next to native Mac UI.

Your Mac input method

Pinyin is composed on the Mac, the candidate window appears on the Mac, and finished characters are sent as Unicode — no double composition, no lost characters.

Cursors that tell the truth

Text, links, resize edges: the cursor shape and its hotspot follow the Windows side, so a click lands where the cursor says it will.

Dragging done locally

Move and resize happen on the Mac immediately; the new geometry is reported to the server when you let go. It doesn't lag behind your hand.

One Dock icon per app

Remote apps get their own Dock icon, so Spotlight, Launchpad and ⌘Tab treat them like anything else on your Mac. Windows 11-style Start menu included.

Multi-monitor aware

Your Mac display layout is mirrored to the remote session, so windows can be dragged across screens the way you expect.

The honest comparison.

Parallels gives you a Windows machine inside your Mac. kkguai assumes you already have one — and turns its apps into Mac windows for free.

As of November 2026. Parallels Desktop requires a Windows licence on top of its own subscription; a Windows Pro licence is required to host RDP.

Three steps. About five minutes.

You need a Windows 10 or 11 Pro PC that stays on, and a network path between the two machines — LAN, VPN or Tailscale all work.

Turn on Remote Desktop on Windows

Run these two lines in an administrator PowerShell, then import enable-remoteapp.reg from the release (administrator, required). Windows Home cannot host RDP.

Install kkguai on the Mac

Download the .dmg, drag kkguai into Applications, and open it. Because the build is not notarized yet, run the xattr line once.

Connect and pick an app

Enter the Windows PC's address and account, then open apps from the Start menu. Each one gets its own Mac window and Dock icon.

Windows · Administrator PowerShell 
# Enable Remote Desktop and allow it through the firewall
Set-ItemProperty 'HKLM:\System\CurrentControlSet\Control\Terminal Server' -Name fDenyTSConnections -Value 0
Enable-NetFirewallRule -Group '@FirewallAPI.dll,-28752'
macOS · Terminal 
# Remove the quarantine flag once, before the first launch
xattr -dr com.apple.quarantine /Applications/kkguai.app
open /Applications/kkguai.app

Questions, answered.

Which Windows version do I need?+
A Windows 10 or 11 Pro (or Enterprise) PC with Remote Desktop enabled. Windows Home cannot host an RDP session.
Does the Windows PC have to stay on?+
Yes. The apps run on that machine; kkguai only displays their windows and sends your input. If it sleeps or disconnects, the windows disappear.
Can I use it outside my LAN?+
Yes. VPN, Tailscale or a port forward all work. We strongly recommend VPN or Tailscale instead of exposing port 3389 directly to the internet.
Why the xattr command on first launch?+
The release is ad-hoc signed but not notarized by Apple, so macOS quarantines it after download. Removing the quarantine flag takes one command, once per install.
How is this different from Parallels?+
Parallels runs a whole Windows virtual machine on your Mac and needs its own subscription plus a Windows licence. kkguai uses a Windows PC you already have, so it costs nothing and doesn't take RAM or CPU from the Mac. The trade-off: that PC must be reachable.
Does it work on Intel Macs?+
The current release is Apple Silicon only. Intel Macs can build from source — see the repository's build section.
Is it secure?+
The connection is standard RDP and is encrypted in transit. Keep it on your LAN, a VPN or Tailscale, use a real account password, and don't expose RDP to the open internet.
