kkguai、Parallels、Windows App、UTM：哪个适合你

四种方案都能让你在 Mac 上用到 Windows 程序，但它们解决的不是同一个问题。有人需要一台「Mac 里的电脑」，有人只是想让公司那台 Windows 上的 ERP 和几个老工具随叫随到。先看清前提，再选工具。

四种方案各自怎么工作

kkguai

把已有 Windows 电脑的程序接到 Mac

用 Windows 自带的 RemoteApp：远程会话只发布单个程序窗口，kkguai 把它显示成 Mac 原生窗口。Windows 在那台电脑上照常运行，Mac 不分配内存和磁盘。

前提：有一台开着的 Windows 10/11 专业版电脑，且两台机器网络可达。

Parallels Desktop

在 Mac 里运行一整台 Windows 虚拟机

虚拟机和它的 Coherence 模式把 Windows 程序窗口直接画到 Mac 桌面上，不需要第二台电脑。Windows 11 ARM 版跑在 Apple Silicon 上，x86 程序靠转译。

前提：订阅费，另需 Windows 授权；占用 Mac 的内存、CPU 和磁盘。

Windows App

微软官方的远程桌面客户端

免费连到另一台 Windows 电脑、Windows 365 云电脑或 Azure 虚拟桌面。默认给你一整块 Windows 桌面，装在一个窗口里。

前提：能远程访问的 Windows 主机；按程序发布需要 AVD / RDS 这类企业设施。

UTM

免费开源的虚拟机

基于 QEMU 与 Apple 虚拟化框架，在 Mac 上开 Windows 或 Linux 虚拟机。没有 Coherence 之类的窗口整合，看到的是完整的 Windows 桌面。

前提：Windows 授权；愿意自己配置和维护虚拟机。

「Windows App」是微软远程桌面客户端的新名字（以前叫 Microsoft Remote Desktop）。它和云端的 Windows 365 / Azure 虚拟桌面是两件事：客户端本身免费。

什么时候该选 kkguai

  • 你已经有那台 Windows 电脑，而且它本来就开着。公司配的台式机、家里的主机、跑 ERP 或财务软件的机器都算。
  • 你只需要几个程序，不需要一个完整的 Windows 桌面。把 ERP、进销存、老版 Office、行业专用工具放到 Mac 桌面上，和邮件、浏览器并排。
  • 你不想为偶尔用到的 Windows 程序付订阅费，也不想让虚拟机吃掉 8 GB 内存和几十 GB 磁盘。
  • 你在意窗口体验：Retina 清晰度、Mac 输入法打中文、每个程序自己的 Dock 图标、多显示器布局同步。

具体安装步骤见 RemoteApp 指南。

什么时候不该选 kkguai

这是本页最重要的部分。kkguai 只是一个 RemoteApp 客户端，它不改变下面这些事实：

  • 那台 Windows 必须开机、联网。出差、断网、电脑休眠，程序就用不了。虚拟机没有这个问题。
  • 必须是专业版或企业版。家庭版不能作为远程桌面主机，没有绕过办法。
  • 重度 3D、视频剪辑和游戏不是它的场景。画面要经过网络编码传输，延迟和画质取决于网络；这类工作用虚拟机或原生 Windows 更合适。
  • 它不会给你一个完整的 Windows 桌面。如果你需要 Windows 的开始菜单、任务栏、文件资源管理器整体来用，用 Windows App 或虚拟机。
  • 它不是微软官方支持的部署方式。公司若通过 RDS / AVD 管理 RemoteApp，应该走公司的方案。

一句话：如果「Windows 在哪运行」这个问题你答不上来，说明你需要的可能是虚拟机；如果你早就有一台在那运行着的 Windows 电脑，kkguai 是最省事的那条路。

三个常见误解

「免费的一定不如付费的」

它们不是同一种产品。Parallels 卖的是在 Mac 里造一台电脑；kkguai 卖的（准确地说是送的）是把已有电脑的窗口接过来。前者功能多得多，后者在本职工作上不花钱。

「RemoteApp 一定要企业服务器」

微软官方的 RemoteApp 部署确实基于 RDS。但 Windows 专业版本身保留了单机发布 RemoteApp 的能力，只是没有图形界面；发布包里的 enable-remoteapp.reg 就是把它打开。这也意味着它依赖 Windows 的既有行为，系统大版本更新后值得留意。

「远程桌面就是把画面传过来，肯定糊」

模糊通常来自按 100% 协商、再被 Mac 放大。kkguai 按 200% 协商会话、按 2 倍像素渲染，文字在 Retina 上能保持清晰；当然，最终的流畅度仍然取决于网络质量。
