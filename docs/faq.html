基本概念

kkguai 是什么？+

kkguai 是一款免费、开源的 macOS RemoteApp 客户端，基于 Pstsc（FreeRDP）构建。它连接一台已有的 Windows 10/11 专业版电脑，把单个 Windows 程序变成 Mac 上的原生窗口：一个程序一个窗口、一个 Dock 图标，可以和平常的 Mac 应用并排使用。

它不是虚拟机，也不是整块远程桌面。程序本身运行在那台 Windows 电脑上，Mac 只负责显示和输入。

需要什么版本的 Windows？+

Windows 10 或 11 的专业版、企业版，或者 Windows Server，并开启「远程桌面」。RDP 不接受空密码账号，所以还需要一个设置了密码的 Windows 账号。

一条命令确认版本：按 Win + R，输入 winver。

Windows 家庭版真的不能用吗？+

作为主机不能。微软从系统层面限制家庭版接受远程桌面连接，设置里没有远程桌面开关，注册表也没有可靠的绕过方法。这不是 kkguai 的限制，而是 Windows 产品线的区别。

可行方向有三个：

  • 把家庭版升级到专业版（需要购买升级或更换授权）。
  • 用 Parallels Desktop 或 UTM 在 Mac 里跑一台 Windows 虚拟机——客户端机器用什么系统版本都行。
  • 把程序换到一台已经是专业版的电脑上运行。详见 方案对比。
Windows 电脑要一直开着吗？+

要。程序运行在那台机器上，kkguai 只负责显示窗口和发送输入。那台电脑休眠、关机或断网，Mac 上的窗口就会消失。

如果它经常休眠，可以在 Windows 的电源设置里把睡眠关掉，办公室台式机通常本来就一直开着。

可以用 Windows Server 做主机吗？+

可以。Windows Server 自带远程桌面服务，导入 enable-remoteapp.reg 之后同样可以作为 RemoteApp 主机使用。服务器版本的多用户授权规则由你的环境决定，kkguai 不改变这部分。

安装与首次启动

为什么首次打开要执行 xattr 命令？+

发布包经过了 ad-hoc 签名，但还没有经过 Apple 的公证（notarization）。macOS 对下载来的应用会加一个隔离标记（com.apple.quarantine），未公证的应用被标记后，系统会拒绝直接启动。

去掉标记只需要一条命令，每次安装执行一次：

macOS · Terminal
xattr -dr com.apple.quarantine /Applications/kkguai.app

之后每次打开都不需要再执行。

不执行 xattr 会怎样？有别的办法吗？+

macOS 会提示「kkguai 已损坏，无法打开」或「无法验证开发者」。这不是文件真的损坏，只是隔离策略。

除了 xattr，也可以在 Finder 里右键点击应用、选择「打开」，然后在弹窗里再确认一次；或者在「系统设置 → 隐私与安全性」里点「仍要打开」。这两种方式同样只对当前安装有效，而且提示文案会因 macOS 版本略有不同。命令行一次执行到底，最不容易出错。

导入 enable-remoteapp.reg 之后需要重启吗？+

需要。注册表改动涉及远程桌面服务的会话行为，重启后才会稳定生效。如果导入后开始菜单里看不到程序，第一件要确认的事就是有没有重启、以及是否用管理员权限导入。

同一个账号已经在 Windows 上登录桌面会话，会怎样？+

单会话模式下，同一账号已经有桌面登录时，新的程序会话可能无法创建，kkguai 会报与「已登录」相关的错误。先在那台电脑上退出桌面会话，再连接。

如果你希望桌面登录和 RemoteApp 并存，按发布包里的说明使用 single-session.reg；不确定的话先不导入，遇到问题再试。

日常使用

支持多显示器吗？+

支持。Mac 的显示器布局会同步给远程会话，窗口可以跨屏拖动，不用每次重新摆一遍。外接屏、Studio Display、合盖接显示器这些常见组合都按 Mac 的布局来。

中文、日文、韩文输入法能用吗？+

能。拼音在 Mac 上合成，候选框在 Mac 上弹出，选好的字以 Unicode 发送到 Windows。远端不会再合成一遍，所以不会出现「打一串出来两遍」或者丢字的情况。日文和韩文输入走同一套机制。

Intel Mac 能用吗？+

当前发布包只支持 Apple Silicon（M 系列），要求 macOS 14 或更新。

Intel Mac 可以从源码自行构建。仓库里有构建说明，需要 Xcode 以及 FreeRDP 的依赖；构建出来的功能与发布包一致，但没有现成的安装包和签名。

能同时打开多个程序吗？+

能。开始菜单里的程序可以同时打开多个，每个都是独立的 Mac 窗口和 Dock 图标，可以分别全屏、分屏或跨显示器摆放。它们共享同一条到 Windows 的连接。

安全与网络

不在同一个局域网能用吗？+

能。只要能建立一条网络可达的路径：VPN、Tailscale、端口转发都可以。Tailscale 会给你一台设备的固定地址或 MagicDNS 名称，直接填进 kkguai 即可。

推荐 VPN 或 Tailscale，而不是在路由器上把 3389 端口转发到公网。

安全吗？RDP 在局域网、VPN 和 Tailscale 上分别怎么样？+

连接走标准 RDP，传输是加密的。安全程度主要取决于你把主机暴露在哪里：

  • 局域网：风险最低。只有同一网络里的设备能尝试连接，配合强密码和账号锁定策略就足够日常使用。
  • VPN：流量包在加密隧道里，外部看不到 RDP 端口。安全性取决于 VPN 本身，公司 VPN 通常已经做了访问控制。
  • Tailscale：基于 WireGuard 的点对点加密网络，设备之间互相认证，端口不对公网开放。对个人用户来说是很省事的选择。

不建议把 3389 直接映射到公网。那会收到大量自动化爆破，即使有密码也不值得冒这个风险。另外请使用带密码的账号，并开启 Windows 的网络级身份验证（NLA）。

数据会不会经过第三方服务器？+

不会。kkguai 是直连客户端：画面和输入在两台设备之间走 RDP 连接，没有中转服务器，也没有账号体系。使用 Tailscale 时，数据走 Tailscale 的加密网络（通常点对点直连），与 kkguai 无关。

替代方案与授权

和 Parallels Desktop 有什么区别？+

Parallels 在 Mac 里运行一整台 Windows 虚拟机，并用 Coherence 模式把程序窗口画到 Mac 桌面上。它需要订阅费（约 $99/年起）和一份 Windows 授权，并占用 Mac 的内存、CPU 和几十 GB 磁盘；好处是离线可用、不需要第二台电脑。

kkguai 用你已有的 Windows 电脑，免费、开源，几乎不占 Mac 资源；代价是那台电脑必须开着并且网络可达，而且必须是专业版。完整对比见 方案对比。

收费吗？开源吗？+

免费，MIT 许可开源，源码在 GitHub 上。没有订阅、没有内购，也没有账号体系。如果它帮你省下了一个 Parallels 订阅，给仓库点个 star 就是最好的支持。

为什么叫 RemoteApp？和微软的 RemoteApp 是一回事吗？+

RemoteApp 是 RDP 协议里「只发布单个程序窗口」的能力，kkguai 用的是 Windows 自带的这套能力。企业里通常通过 RDS / AVD 部署微软官方的 RemoteApp；kkguai 面向的是单台 Windows 专业版电脑，用发布包里的注册表文件打开这项能力。两者在协议层是同一件事，部署方式不同。
